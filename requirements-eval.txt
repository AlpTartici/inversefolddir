# Inverse FoldDir -- optional dependencies for the structural evaluation pipeline.

# NOT needed to design sequences. Install these only if you want to run
# eval/evaluation_pipeline.py, which refolds designs and scores them against the

# These are separated out because they are heavier and less portable than the
# design dependencies: transformers pulls a large stack, and parasail is a
# compiled extension without wheels for every platform.
