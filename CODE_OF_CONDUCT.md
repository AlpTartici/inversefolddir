# Code of Conduct

This project inherits the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/),
adopted by the upstream repository
[microsoft/InverseFoldDir](https://github.com/microsoft/InverseFoldDir) from
which this work is derived. Participants in this repository are expected to
follow the same standards of respectful, professional conduct.

## Reporting

**This repository is maintained independently of Microsoft.** Report concerns
about conduct in *this* repository to the maintainer:

- **tartici@stanford.edu**

Reports about the upstream Microsoft-hosted project should go to Microsoft
instead, at [opencode@microsoft.com](mailto:opencode@microsoft.com). Microsoft
does not moderate this repository.
